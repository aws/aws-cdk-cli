The AWS CDK Toolkit CLI provides the `cdk` command-line interface that can be used to work with AWS CDK applications. This module is part of the [AWS Cloud Development Kit](https://github.com/aws/aws-cdk) project.

Prefer the [`aws-cdk`](https://www.npmjs.com/package/aws-cdk) package, which is the canonical distribution of the AWS CDK Toolkit CLI and where the documentation lives. This package is an alias that depends on `aws-cdk` at the exact same version and exposes the identical `cdk` command.
